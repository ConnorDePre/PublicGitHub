 # About

In today’s digital landscape, most media platforms revolve around videos, pictures, and livestreams. But there lacks the initiative to create communities that bond over literature, especially where such literature can be shared in new and unique ways. Modern platforms often prioritize passive consumption over genuine connections. Our goal is to bring back the social in social media by empowering users to share their stories, ideas, and imaginations in new formats. 

DigiCover is a social platform where books aren’t limited to words on a page. Users can create interactive learning materials, art portfolios, study journals, or stories. These combine the powers of text, images, videos, and GIFs into products that can then be shared to a vibrant community where readers can follow, save, and revisit works. With personalized libraries, educational discovery feeds, creator monetization, and customization options, this platform makes extended reading, learning, and creativity both social and inspiring. Users can create these digital books and post as it’s worked on or the final product as a whole for the entire community to view and interact with the work.

# How to Run Locally

 1. Enter in Console 'npm i' this install latest libraries needed found in package.json
 2. To ensure everything is working from a code perspective, enter the following in console: 'npm run build'
 3. To open the site to test code function and visuals, enter the following in the console: 'npm run dev'

# How to update code

1. Click on the ticket you want to work on the Jira board
2. Right side of description you should see a 'Development' option, select this
3. Select Create Branch, and enter the following:
    - Select Repo: SantiCS26/DigiCover
    - Branch from main
    - Branch name: Ticket-Number (Example: DIG-41)
    - Click 'Create Branch'
4. The branch is now created, run git pull on VS Code and start coding in that branch
5. Every commit should be titled with ticket number (EX: DIG-41) and pushed only to the ticket branch
6. Once code is tested and Verified Create a Pull Request to main, description is optional, and someone will verify before merging to main [WARNING - This is the official release branch so be careful]

 ------------------------------------------

 # How to test code

 1. Run tests in terminal to ensure all test cases pass if any exist.
 2. Run the build to ensure the project is able to build.
 3. Run the project locally, and open to test the new features and ensure everything works as intended.
 4. Final PR will be reviewed by someone as well before merging to main.
